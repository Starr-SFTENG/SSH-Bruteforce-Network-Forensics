**SSH Brute-Force Network Forensics Investigation**

**Overview**

This project documents a digital forensic investigation into an automated SSH brute-force attack detected within a controlled virtual lab environment. Network traffic was captured and analyzed to identify attack behavior, indicators of compromise, and security implications.



🧪**Lab Environment**


-Kali Linux (Attacker)

-Ubuntu Server (Target)

-Windows 10 (Analysis)

-Tools: tcpdump, Wireshark



🔍 **Investigation Summary**

-Detected TCP SYN scanning activity

-Identified repeated SSH session attempts

-Confirmed automated client usage (libssh)

-No successful authentication observed



📄**Deliverables**

-Network PCAP analysis

-Formal forensic report (PDF)

-Indicators of compromise (IOCs)

-Wireshark filters and analysis notes


🛡️**Skills Demonstrated**

-Network traffic analysis

-Digital forensics methodology

-Incident response documentation

-Evidence handling and reporting
