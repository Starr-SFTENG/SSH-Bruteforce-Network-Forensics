# SSH Brute-force PCAP & Log Correlation

## Case Overview
This repository contains a case study analyzing an SSH brute-force attack using system authentication logs and packet capture (PCAP) data. The goal is to correlate login attempts with network traffic to reconstruct the attack timeline and extract relevant evidence.

- **Attack Type:** SSH brute-force
- **Victim Server:** cyberserver (192.168.56.103)
- **Attacker Host:** 192.168.56.102
- **Key Evidence:** Authentication logs, PCAP capture
